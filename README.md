PSX Music Player & Configuration Menu
=====================================

A hybrid desktop application and web interface that replicates the nostalgic experience of the classic PlayStation 1 CD player. 
This project allows you to customize, patch, and build your own retro audio player configuration.

= Choose your Visualizer Style =

Main Menu:
First, open the Settings menu within the application.

Mode 1:
Copy the full suite of original visualizer presets directly to your active player engine.

Mode 2:
Copy a completely different, custom-colored variation suite of visualizer presets directly to your active player engine.

Custom Visualizer Style:
Build a custom mix by clicking individual animated preview boxes. 
You can independently select or deselect specific visual modes for both Mode 1 and Mode 2.

Custom Shift Timers:
4 dedicated timer buttons allow you to lock down visualizer rotation speeds at 5, 10, 15, or 20-second intervals. 
Click one of the four buttons to decide how long each visual mode stays on screen before shifting.

Instant Script Patching:
Features a real-time regex compiler that modifies the player's underlying JavaScript file on the fly based on your menu selections.

Compile the Player:
Click Patch to automatically rewrite and lock your custom visual selection and timer configuration directly into the player's engine script.


= Launching & Using the Player =

Launching the Player:
In settings, click the PSX Player button on top—this will close the configuration menu and immediately launch the Web Player.

Alternatively, press the Exit button to go back to the Main Menu, and press the main PSX Player button from there the old-school way.


Load your Audio Files:
On the Web Player interface, click the + icon to add up to 1,000 songs to your player session. 
Once you select your desired MP3 files, they will dynamically populate the visual track slots.


Switching Between Track Slots:
Since the interface screen displays a maximum of 20 track slots at once, you can click the blue sphere located below the track slots to flip pages. 
This shifts the display to the next page so you can view the next 20 songs in your list. Keep cycling through the pages to loop back to the first page.


Audio Track ID:
Hover your custom glove cursor over any track slot for 1 second to reveal its track ID tooltip. 
The active track ID of the currently playing audio file will always display directly on the player's main timer screen.

= Playback Modes =

Continue: Standard sequential playback of your loaded audio files.

Shuffle: Random track playback order.

Program: Allows you to program a specific custom playlist by manually clicking track slots to decide exactly which tracks play and in what order.

Repeat/All: Loops either the current single track or the entire loaded audio list.

Time: Cycle through remaining time of the current playing audio, total time of all (selected) audio, and countdown total time of all (selected) audio.
= Activate Visual Modes =

Once the audio is playing, toggle the small gold sphere located in the timer display between the minutes and seconds to activate the visual modes.
